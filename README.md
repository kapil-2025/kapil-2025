### 📂 Featured Projects

#### 💬 Realtime Chat App
[Live Demo](https://realtime-chat-app-wheat-beta.vercel.app) · [Code](https://github.com/kapil-2025/realtime-chat-app)

WhatsApp-style real-time chat app, live on Vercel + Render.
- **Real-time 1:1 messaging** with Socket.IO, synced across devices
- Signup with **email OTP** verification, plus **Google Sign-In**
- **Forgot password** flow with OTP; old login tokens stop working after a reset
- **Secured WebSockets**: JWT checked during the Socket.IO handshake
- API protected with **Helmet, rate limiting and Zod validation**
- Coming next: online status, typing indicator, image sharing, audio and video calls

#### 🔐 Auth Role Dashboard
[Live Demo](https://auth-role-dashboard.vercel.app) · [Code](https://github.com/kapil-2025/auth-role-dashboard)

Full-stack MERN app with secure login and role-based access, used by 10+ users.
- Register and login with **JWT authentication** and bcrypt-hashed passwords
- **Role-based access**: users get a dashboard, admins get an admin panel
- Admins can view and delete users, with role checks on the server
- REST API built with **Express + MongoDB Atlas**, deployed on **Render**
- **React + Tailwind** frontend, deployed on **Vercel**
